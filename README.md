# Калькулятор на C++

Консольное приложение на языке C++, предназначенное для выполнения основных арифметических и унарных операций над двумя целыми числами.

## 📌 О проекте

Проект разработан в рамках учебного задания по программированию на C++. Основная цель — закрепить навыки работы с переменными, условными операторами, циклами и обработкой пользовательского ввода.

## ⚙️ Возможности

### Арифметические операции
- **Сложение (`+`)** — сложение двух чисел.
- **Вычитание (`-`)** — вычитание второго числа из первого.
- **Умножение (`*`)** — умножение двух чисел.
- **Деление (`/`)** — деление первого числа на второе.
- **Проверка деления на ноль** — предотвращение деления на ноль.

### Унарные операции
- **Инкремент (`++`)** — увеличение выбранного числа на единицу.
- **Декремент (`--`)** — уменьшение выбранного числа на единицу.
- Возможность повторного выполнения выбранной операции.

### Дополнительные возможности
- Интерактивное консольное меню.
- Выбор числа для выполнения унарной операции.
- Обработка некорректного выбора пунктов меню.
- Проверка ошибок при вводе чисел.


## 📋 Ограничения

- Для вычислений используются целочисленные переменные типа `int`.
- При делении дробная часть результата отбрасывается.
- Для корректной работы с русским текстом используются настройки кодировки консоли Windows.
- Для предотвращения переполнения при арифметических и унарных операциях необходимо проверять допустимость операции до её выполнения.

## 📚 Цель обучения

В процессе разработки закрепляются следующие навыки:

- Работа с типами данных и переменными.
- Использование `if`, `else if` и `else`.
- Организация циклов с помощью `while`.
- Использование операторов `+`, `-`, `*`, `/`, `++` и `--`.
- Проверка корректности пользовательского ввода.
- Обработка недопустимых операций.
